# NautilusTrader Practical Tutorials

A systematic tutorial series for the NautilusTrader high-performance algorithmic trading framework — from installation and the backtest engine to live trading architecture and complete project walkthroughs.

## Learning Path

| Stage | Chapters | Topics |
|------|------|------|
| Beginner | 1–3 | Framework intro, installation, quickstart |
| Core | 4–8 | Data import, backtest engine, time events, indicators, order management |
| Intermediate | 9–12 | Portfolio & risk, advanced data, message actors, performance tuning |
| Practical | 13–16 | Live architecture, exchange integration, strategy deployment, algo trading |
| Advanced | 17–18 | Machine learning / AI, custom component development |
| Wrap-up | 19–21 | Two complete projects and conclusion |
